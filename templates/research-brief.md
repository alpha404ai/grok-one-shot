# research-brief

```xml
<task>
Goal: answer "{{QUESTION}}" in one page.
Done: a 2-line answer at the top, then 3 to 5 supporting points with sources.
Context: {{FILES_OR_LINKS}}, 3 max.
</task>
<plan>
1. Write the question in your own words. Show it.
2. Find the strongest evidence on each side.
3. Write the 2-line answer.
4. Add 3 to 5 points, each with a source.
5. Add one line: what would change this answer.
</plan>
<stop>
The sources do not answer the question: say so. Do not fill the gap.
</stop>
```
